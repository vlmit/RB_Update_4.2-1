Для компиляции расширений требуется:
1. Установленная Visual Studio 2026. Возможна установка бесплатной Community Edition.
2. Если используется другая IDE, помимо Visual Studio, то потребуется также установить .NET SDK 10.0.x последней доступной версии: https://dotnet.microsoft.com/download/dotnet/10.0

Для развёртывания веб-сервиса на IIS требуется установить .NET Runtime & Hosting Bundle последней доступной версии 10.0.x:
https://dotnet.microsoft.com/download/dotnet/10.0
