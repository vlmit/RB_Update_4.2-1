# Playground

Чтобы открыть песочницу нужно:

- Залогиниться под администратором
- Открыть девтулзы браузера (F12)
- В консоли выполнить `sessionStorage.setItem('playground', true)`
- Перезагрузить вкладку браузера
- Теперь песочницу можно открыть по тайлу `Playground` или перейти по пути `{myserver}/playground`
